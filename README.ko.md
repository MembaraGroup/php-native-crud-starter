## 이 등급은 누구를 위한 것인가요?

- 처음 코더를 접하는 사람과 생후 0~6개월의 학생.
- 일반 PHP 페이지가 실제 SQLite CRUD 흐름에 어떻게 연결되는지 확인하려는 초보자.
- AI 도구에 코드 수정을 요청하기 전에 작고 안정적인 참조를 원하는 개발자.

## 최고의 대상

- 프레임워크 추상화 없이 CRUD 기본을 학습합니다.
- 간단한 경로를 연구하고 추적하기 쉬운 흐름을 봅니다.
- 수동 코딩 및 AI 분위기 코딩 프롬프트를 위해 실행 가능한 기준선을 사용합니다.

## 대상이 아님

- 이미 CSRF 보호 및 검색 가능한 DataTable이 필요한 구매자.
- 이미 컨트롤러, 모델, 뷰 경계가 필요한 주니어 프로그래머.
- 이미 대시보드, 보고서 또는 설정이 필요한 상용 내부 도구 작업입니다.

## 이 등급을 선택하는 이유

마찰을 제거하기 위해 스타터가 존재합니다. 이는 이미 실행되고 읽기 가능한 상태를 유지하며 과도한 추상화 없이 전체 요청-데이터베이스 경로를 노출하는 하나의 작은 기본 PHP CRUD를 제공합니다.

## 이전 계층에서 업그레이드해야 하는 이유

스타터는 입문 계층입니다. 보다 안전한 양식, DataTables 목록 유용성, 더 큰 프로젝트 구조로 바로 뛰어들지 않고도 보다 깔끔한 초급에서 중급으로의 전환을 원할 경우 PreBasic으로 이동하십시오.

| --- | --- | --- | --- | --- | --- |
| 오늘 구축된 데이터베이스 | SQLite | SQLite | SQLite + MySQL | MySQL | MySQL |
| 데이터테이블 UI | 아니요 | 예 | 예 | 예 | 예 |
| 양식의 CSRF | 아니요 | 예 | 예 | 예 | 예 |
| 컨트롤러, 모델 및 뷰 구조 | 아니요 | 아니요 | 예 | 예 | 예 |
| 대시보드 | 아니요 | 아니요 | 아니요 | 예 | 예 |
| 필터 및 CSV 내보내기 | 아니요 | 아니요 | 아니요 | 예 | 예 |
| 보고서, 활동 로그, 설정 | 아니요 | 아니요 | 아니요 | 아니요 | 예 |
| 액세스 모드 | 공공 기부 | 유료/비공개 | 유료/비공개 | 유료/비공개 | 유료/비공개 |

## 이 프로젝트를 지원하는 이유

기부를 통해 무료 등급이 오래되지 않고 유용하게 유지됩니다. 지원 자금:

- 공개 SQLite 스타터 유지 관리
- Docker 및 연기 테스트 검증
- 문서, 스크린샷 및 온보딩 마무리
- 유료 계층이 기반으로 구축되는 하위 계층 기준

무료란 버려지는 것이 아니라 관대함을 느끼는 것을 의미합니다. 기부는 그 약속을 현실로 유지하는 데 도움이 됩니다.
