# Donate

The public Starter tier stays free so beginners can learn from a runnable native PHP CRUD baseline.

Primary support path:

```text
https://github.com/sponsors/andiupn?frequency=monthly
```

## What Donations Help Fund

- Free-tier maintenance and bug fixes
- Docker and smoke-test verification
- README, screenshots, and onboarding improvements
- compatibility work that keeps the starter usable as a stable learning and AI-reference baseline

## What Donation Is Not

Donation supports the public free tier. It is not the same as buying access to the private paid tiers.

If you need stronger features such as CSRF, DataTables, controller and model structure, dashboard, reports, or settings, use the paid upgrade path through the higher tiers.

## What Stays Free

- the current `php-native-crud-starter` baseline
- public documentation for the starter tier
- donation-friendly public access to the starter repository
