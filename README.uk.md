Рідний PHP CRUD-стартер для початківців для ручного навчання та кодування за допомогою штучного інтелекту, із загальнодоступним шляхом пожертвування, який допомагає підтримувати безкоштовний рівень стабільним.

Додатковий заклик до дії: [Оновіть до PreBasic або Basic для підвищення рівня](https://github.com/sponsors/andiupn?frequency=monthly)

## Для кого цей рівень

- Початківці кодери та студенти в перші 0-6 місяців.
- Початківці, які хочуть побачити, як прості сторінки PHP підключаються до реального потоку SQLite CRUD.
- Розробники, яким потрібна невелика стабільна довідка, перш ніж просити інструменти ШІ змінити код.

## Найкраще для

- Вивчення основ CRUD без фреймворкової абстракції.
- Вивчення простого маршруту та оглядового потоку, який легко простежити.
- Використання базової лінії для ручного кодування та підказок кодування AI Vibe.

## Не для

- Покупці, яким уже потрібен захист CSRF і доступні для пошуку таблиці даних.
- Молодші програмісти, яким уже потрібен контролер, модель і межі перегляду.
- Комерційна робота внутрішнього інструменту, яка вже потребує інформаційної панелі, звітів або налаштувань.

## Чому варто вибрати цей рівень

Стартер існує для усунення тертя. Він дає вам один невеликий рідний PHP CRUD, який уже працює, залишається читабельним і відкриває повний шлях запиту до бази даних без важких абстракцій.

## Навіщо оновлюватися з попереднього рівня

Початковий — початковий рівень. Переходьте до PreBasic, якщо вам потрібні безпечніші форми, зручність використання списків DataTables і чистіший перехід від початківців до молодших, не переходячи безпосередньо до більшої структури проекту.

## Навіщо підтримувати цей проект

Пожертви зберігають безкоштовний рівень корисним, а не старим. Кошти підтримки:

- обслуговування публічного стартера SQLite
- Перевірка докерів і димових тестів
- документація, скріншоти та інструкція
- базова лінія нижчого рівня, на основі якої будуються платні рівні

Вільний означає почуватися щедрим, а не покинутим. Пожертви допомагають виконати цю обіцянку.

