Нативный PHP CRUD для начинающих для ручного обучения и кодирования с помощью искусственного интеллекта, а также публичный путь пожертвований, который помогает поддерживать стабильный уровень бесплатного пользования.

Основной призыв к действию: [Пожертвовать на поддержку бесплатного обслуживания](https://github.com/sponsors/andiupn?frequency=monthly)
Вторичный призыв к действию: [Обновите до PreBasic или Basic для более высоких уровней](https://github.com/sponsors/andiupn?frequency=monthly)

## Для кого предназначен этот уровень

- Начинающие программисты и учащиеся в первые 0–6 месяцев.
- Новички, которые хотят увидеть, как простые страницы PHP подключаются к реальному потоку CRUD SQLite.
- Разработчики, которым нужен небольшой стабильный справочник, прежде чем просить инструменты искусственного интеллекта изменить код.

## Лучшее для

- Изучение основ CRUD без абстракции фреймворка.
- Изучение простого маршрута и просмотра потока, который легко проследить.
- Использование работоспособной базовой линии для ручного кодирования и подсказок по кодированию AI Vibe.

## Не для

- Покупатели, которым уже нужна защита CSRF и таблицы данных с возможностью поиска.
- Младшие программисты, которым уже нужны контроллер, модель и границы представления.
- Коммерческая работа с внутренними инструментами, для которой уже необходимы панель мониторинга, отчеты или настройки.

## Почему стоит выбрать этот уровень

Стартер существует для устранения трения. Он дает вам один небольшой собственный PHP CRUD, который уже работает, остается читаемым и предоставляет полный путь запроса к базе данных без тяжелых абстракций.

## Зачем переходить с предыдущего уровня

Starter — начальный уровень. Перейдите на PreBasic, если вам нужны более безопасные формы, удобство использования списков DataTables и более чистый переход от новичка к младшему, не переходя сразу к более крупной структуре проекта.

## Зачем поддерживать этот проект

Пожертвования делают уровень бесплатного пользования полезным, а не устаревшим. Средства поддержки:

- обслуживание публичного стартера SQLite
- Проверка Docker и дымового теста.
- документация, скриншоты и вводная информация
- базовый уровень нижнего уровня, на основе которого строятся платные уровни.

Свободный означает чувствовать себя щедрым, а не брошенным. Пожертвование помогает сдержать это обещание.

## Быстрый старт

```bash
cd php-native-crud-starter
docker compose up --build
```

Открыто:

```text

```
