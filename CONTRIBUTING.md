# Contributing

Thanks for helping improve the public Starter tier.

## What Contributions Fit This Repo

- bug reports with clear reproduction steps
- documentation fixes
- typo and clarity improvements
- safe fixes that keep the Starter tier simple and beginner-friendly

## What Usually Does Not Fit

- framework migration requests
- features that belong to higher tiers such as DataTables, CSRF, dashboard, reports, or settings
- large refactors that make the code harder for first-time learners to trace

## Before Opening A Pull Request

Run:

```bash
./scripts/lint.sh
./scripts/smoke.sh
```

## Security Reports

Do not open public issues for security vulnerabilities. Use the contact path in [SECURITY.md](SECURITY.md).
